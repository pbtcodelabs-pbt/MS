# 💊 میڈیسن شیلف (MS)

دوائیوں کا مکمل اردو ریکارڈ — ایک PWA ایپ جو GitHub Pages پر چلتی ہے۔

## خصوصیات
- دوائی کا نام، بنانے والی کمپنی (اردو یا انگلش)، قیمت، استعمال کی تاریخ، علامات اور نوٹ
- 📷 اسکینر: دوائی کے ڈبے کی تصویر سے نام، کمپنی اور قیمت خود خانے میں
- 🔍 ادھوری تلاش: نام، کمپنی، علامات، شخص یا تاریخ سے
- 👤 زمرے: ہر دوائی کس کی ہے (مثلاً عبدالحفیظ کی دوائی)
- 📤 ایک یا کئی دوائیاں واٹس ایپ پر شیئر؛ 📥 لنک یا فائل سے وصول کر کے محفوظ
- 💾 بیک اپ اور بحالی، آف لائن چلتی ہے
- فونٹ: جمیل نوری نستعلیق اور نوری نستعلیق کشیدہ

## فائلیں
| فائل | کام |
|---|---|
| `index.html` | پوری ایپ |
| `sw.js` | آف لائن کیش |
| `manifest.json` | فون پر انسٹال |
| `icon.svg` | آئیکن |
| `fonts/` | نوری نستعلیق + کشیدہ |
